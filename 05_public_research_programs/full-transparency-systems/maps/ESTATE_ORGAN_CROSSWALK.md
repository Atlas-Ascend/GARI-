## Do-not-duplicate enforcement

FTS creates no new memory cortex, executive authority, task substrate, workforce router, engineering factory, audit authority, disclosure gate, runtime body, evidence ledger, field-capture system, or I/O router.

New FTS code is limited to reusable protocol components that mount behind these authorities, including:

- audit schemas;
- domain adapters;
- control-pack adapters;
- contradiction detection;
- chronology normalization;
- power/incentive mapping;
- audit campaign templates;
- reproducibility exporters;
- reviewer/public projections.

`TARGET -> CONNECTOR/FIELD CAPTURE -> GARI NORMALIZATION -> UNIVERSAL ATLAS IDs -> SESHAT SYSTEM GRAPH -> THOTH PROVENANCE -> ALETHEIA EVIDENCE LATTICE -> CONTROL PACKS -> SECA/MA'AT TEST+VERDICT -> JANUS REMEDIATION AUTHORITY -> PACKET OS/WORKFORCE -> PROMETHEUS/METAFORGE/EDEN -> RETEST -> MEDUSA -> THOTH/PROOFGRID -> CASEGRAPH/PUBLIC SURFACE`

## FTS as the estate's external governance doorway

The Ghost Atlas Estate remains the organism. FTS becomes the repeatable method through which that organism can encounter an external system, understand it, test it, repair what is authorized to be repaired, and return a proof-bearing audit state.
