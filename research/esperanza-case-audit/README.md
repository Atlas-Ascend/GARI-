# GARI Esperanza Case Audit

**Object:** `GARI-ESPERANZA-CASE-AUDIT-001`

This research/audit object normalizes the Esperanza Village matter into a command-to-proof structure inside GARI.

## Active baseline

- Master case spine: EV-001 through EV-026
- Evidence rule: no assertion is promoted above the evidentiary strength of its strongest source
- Conflicts are preserved as conflicts until reconciled
- Self-authored contemporaneous records are distinguished from third-party and native transactional records
- Administrative claims, observations, interpretations, and external corroboration are kept separate

## Structure

- `MASTER_CASE_SPINE.md` — canonical event ledger
- `EVIDENCE_INDEX.md` — evidence classes and proof targets
- `REQUEST_RESPONSE_MATRIX.md` — requests, recipients, responses, and status
- `PROOF_GATES.md` — promotion gates and unresolved proof requirements
- `SOURCE_RECONCILIATION.md` — source conflicts and normalization notes
- `META_FATE.md` — object identity and estate routing

## Command-to-proof doctrine

Every material assertion should be traceable backward to a source artifact. Where the source is self-authored, the ledger says so. Where CCA, APS/ODHS, crisis services, or another external body generated the record, that is marked separately. Unknowns remain unknowns until resolved.
